# UPI Fraud Analysis Dashboard

A Power BI based data analytics dashboard to visualize and analyze UPI fraud patterns using synthetic transaction data.

## 📊 Project Overview
This project analyzes 100K+ synthetic UPI fraud transactions to identify key patterns in cities, apps, and time. 
The goal is to help understand where and when UPI frauds are most likely to occur.

## 🔍 Key Insights from Dashboard
Based on the analysis of `upi_fraud_sample.csv`:

1.  **Fraud Count by City**: **Mumbai** has the highest fraud count, followed by **Bangalore, Hyderabad, Chennai, Delhi, and Coimbatore**
2.  **Fraud by UPI App**: Fraud is almost equally distributed across **GPay - 33.48%**, **Paytm - 33.34%**, **PhonePe - 33.18%**
3.  **Fraud Count by Hour**: Peak fraud activity occurs between **12 AM to 4 AM**. After 5 AM fraud count drops significantly
4.  **Total Fraud Transactions**: **100.00K** fraud cases identified in the dataset
